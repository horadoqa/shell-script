Atalhos do Terminal Linux

Cheat sheet dos principais atalhos de teclado para navegar, editar comandos, controlar processos e trabalhar com o histórico.

bash — terminal
user@linux:~$ ls -la
user@linux:~$ git status
user@linux:~$ _

↔ Navegação na linha

Início da linha
Ctrl + A
Fim da linha
Ctrl + E
Move 1 caractere para trás
Ctrl + B
Move 1 caractere para frente
Ctrl + F
Move 1 palavra para trás
Alt + B
Move 1 palavra para frente
Alt + F
Move 1 palavra para trás
Ctrl + ←
depende do terminal
Move 1 palavra para frente
Ctrl + →
depende do terminal

✂ Apagar e editar

Apaga o caractere anterior
Ctrl + H
Apaga o caractere sob o cursor
Ctrl + D
Apaga a palavra anterior
Ctrl + W
Apaga a próxima palavra
Alt + D
Apaga até o início da linha
Ctrl + U
Apaga até o fim da linha
Ctrl + K
Cola o último texto apagado
Ctrl + Y
Alterna textos apagados anteriormente
Alt + Y

↶ Histórico

Comando anterior
Ctrl + P
Próximo comando
Ctrl + N
Pesquisa reversa no histórico
Ctrl + R
Pesquisa para frente
Ctrl + S
pode depender da configuração
Cancela pesquisa do histórico
Ctrl + G
Primeiro comando do histórico
Alt + <
Último comando do histórico
Alt + >

⚡ Controle do terminal e processos

Interrompe o comando/processo atual
Ctrl + C
EOF / sai do shell se a linha estiver vazia
Ctrl + D
Suspende o processo atual
Ctrl + Z
Limpa a tela
Ctrl + L
Pausa a saída do terminal
Ctrl + S
Retoma a saída do terminal
Ctrl + Q
Envia SIGQUIT ao processo
Ctrl + \

⌨ Manipulação do comando

Troca o caractere atual com o anterior
Ctrl + T
Troca a palavra atual com a anterior
Alt + T
Converte palavra para MAIÚSCULAS
Alt + U
Converte palavra para minúsculas
Alt + L
Capitaliza a palavra
Alt + C
Alterna entre posição atual e início da linha
Ctrl + XX

⭐ Os que mais valem decorar

  • Ctrl+A Início da linha
  • Ctrl+E Fim da linha
  • Alt+B Palavra para trás
  • Alt+F Palavra para frente
  • Ctrl+U Apaga até o início
  • Ctrl+K Apaga até o fim
  • Ctrl+W Apaga palavra anterior
  • Ctrl+Y Cola o texto apagado
  • Ctrl+R Pesquisa no histórico
  • Ctrl+L Limpa a tela
  • Ctrl+C Interrompe comando
  • Ctrl+Z Suspende processo
  • Ctrl+D EOF / sair
💡 Macete para memorizar:

A = início  ·  E = End  ·  B = Back  ·  F = Forward  ·  K = Kill até o fim  ·  U = até o início
